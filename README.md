# Asmit Rawat — Portfolio Website

Personal portfolio and systems architecture showcase for Asmit Rawat, highlighting local-first AI systems, security gateways, and 3D web animations.

## Key Features
- **3D Particle Sculptures:** Canonical face mask, relativistic singularity, torus knot, and wavefield presets with smooth real-time morphing.
- **Torn Paper Design Aesthetic:** Custom craft paper containers with deckle edges and washi tape styling.
- **Agent OS Sandbox:** Interactive terminal demonstrating structured action parsing, DLP filters, and state rollback.
- **Animation Laboratory:** Live gallery with adjustable physics parameters (speed, turbulence, color themes).
- **Audio Synthesis:** Procedural sound effects via Web Audio API.

## Tech Stack
- React 19, TypeScript, Vite
- Tailwind CSS v4
- Three.js, GSAP
- Lucide React

## Local Setup
```bash
npm install
npm run dev
```
